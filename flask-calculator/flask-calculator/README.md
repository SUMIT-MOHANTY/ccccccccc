# Flask Calculator

A minimalist web-based calculator built with Flask backend and static HTML/JS frontend.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Responsive design for mobile and desktop
- Error handling for edge cases (division by zero, invalid input, etc.)
- JavaScript and non-JavaScript compatibility
- Sample calculation examples
